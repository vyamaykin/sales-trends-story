# When do our stores sell the most?

A one-page scrolling story of MERS Goodwill store sales, January 2024 to November 2026:
record sales days, day-of-week and month patterns by division, district, location type and store,
and the 2027 plan.

Open `index.html` in a browser. Everything is in that one file (data included); the charts load
Chart.js from cdnjs.

Sales totals come from the daily sales report (all stores). Weekday, month and store patterns use
the 65 active stores. Sales only, no profit.
